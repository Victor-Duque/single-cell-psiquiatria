# Single Cell - Psiquiatria

Tutorial de análise de snRNA-seq aplicada à genética psiquiátrica, em R/Seurat, usando dados públicos do córtex pré-frontal de pessoas com depressão maior e controles:

> Maitra M, Mitsuhashi H, Rahimian R *et al.* Cell type specific transcriptomic differences in depression show similar patterns between males and females but implicate distinct cell types and genes. *Nat Commun* 14, 2912 (2023). https://doi.org/10.1038/s41467-023-38530-5

## Ver o tutorial

Tutorial completo, com códigos, figuras e resultados: **https://victor-duque.github.io/single-cell-psiquiatria/**

## Rodar no seu computador

1. Baixe este repositório (**Code → Download ZIP**) e abra o arquivo `single-cell-psiquiatria.Rproj` no RStudio.
2. Baixe o [`Data.rds`](https://github.com/Victor-Duque/single-cell-psiquiatria/releases/download/v1.0-dados/Data.rds) e coloque em uma pasta chamada `dados/`.
3. Abra o `Single_Cell_Psiquiatria.qmd` e rode os chunks em ordem.

Dados originais: [GEO GSE213982](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE213982) e [UCSC Cell Browser](https://dlpfc-mdd.cells.ucsc.edu).
